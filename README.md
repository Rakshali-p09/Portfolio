# My Portfolio

A personal portfolio website built with React to showcase my skills, projects, education, and experience.

## 🌐 Live Demo

**[View My Portfolio](https://rakshali-p09.github.io/Portfolio/)**

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* React Router
* Git & GitHub
* GitHub Pages

## ✨ Features

* Responsive portfolio design
* Home section
* About Me section
* Skills section
* Projects section
* Contact section
* Navigation between sections/pages
* Deployed using GitHub Pages

## 🚀 Run Locally

To run this project on your computer:

```bash
git clone https://github.com/Rakshali-p09/Portfolio.git
cd Portfolio
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

> The localhost link is only for running the project locally. For the deployed version, use the Live Demo link above.

## 📦 Build

To create a production build:

```bash
npm run build
```

## 🚀 Deployment

This portfolio is deployed using **GitHub Pages**.

To deploy an updated version:

```bash
npm run deploy
```
